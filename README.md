# 웅덩이 트레이더 (MVP)

미국 + 국내 종목의 하락 구간 분할매수 신호를 점수로 보여 주는 모바일 우선 PWA. 문서(`../01_PROMPTS.md`, `../02_BUILD_GUIDE.md`)를 기준으로 만든 구현입니다.
**투자 권유가 아닙니다.** 아래 "검증 결과 요약"을 먼저 읽으세요.

## 실행
```bash
python tools/update_data.py   # 시세 수집(야후 차트, 비공식). 접근 제한 시 우회하지 않고 기존 데이터 유지
python server.py              # http://localhost:8000
```
국내 개별주 적정가(도키): DART 인증키(영문·숫자 40자)를 환경변수 `DART_API_KEY`에 설정한 뒤
```bash
python tools/fund_kr.py       # 키 형식이 틀리면 값을 출력하지 않고 중단. --selftest 로 계산식만 점검
```

## 구현됨
- `data/universe.json`: 49종목(미국 26, 국내 23) · 시장(US/KR) · 레버리지 배율 · 그룹(index/sector/stock/leverage)
- `tools/update_data.py`: 전체 이력 수집 → 이후 최근 1개월 병합, 실패 시 기존 값 유지. 수정주가 오류(0 이하)가 있으면 원 종가 사용
- `tools/fund_kr.py`: DART 영업현금흐름·주식수(보통주+우선주)로 적정가, 공시일 이력(룩어헤드 방지), 금융업 제외
- `engine.js`: 웅덩이·도키·통합 점수, 1~3차, 과열 시 신규 매수 중단, 레버리지 제한. 시장별 컨텍스트(US=VIX·VIX3M, KR=코스피 실현변동성 백분위)와 공통 지표(섹터 ETF 시장 폭, 자체 공포지수)
  - 웅덩이 신호 13개: 낙폭, 200일선 이격, 주봉·일봉 RSI, MACD, 변동성, 지수 낙폭, 시장 폭, 자체 공포지수, VIX 기간구조(미국), 계절성(미국), 200주선 근접, 추세 돌파. 시장에 없는 신호는 빼고 나머지로 정규화
  - 화면은 신호가 켜진 지 11거래일 이내인 "신규"와 그 이후 "지속"을 구분(검증과 같은 신호 구간 규칙). 내 계좌 권장 상한은 신규만 계산
- `bt-worker.js`: 이벤트 연구(기준선·표본 외), 매매 시뮬레이션(수수료·거래세), 신호별 효과 점검, 자동 보정(워크포워드)
- 화면: 오늘 / 종목(차트·체크리스트·적정가) / 검증(중립 ETF 유니버스 분리) / 내 계좌(기기 내 저장). 서비스 워커·매니페스트

## 검증 결과 요약 (2026-11-13 데이터 기준)
- 1차 신호 후 60일 상승 확률은 아무 날 매수 기준선과 같거나 낮았습니다(중립 ETF: 미국 64.5% vs 66.8%, 국내 51.5% vs 54.7%).
- 매매 시뮬레이션은 100% 보유와 연수익률이 같고 최대낙폭은 약 2%p 얕았습니다.
- 변동성 신호(미국 VIX, 국내 자체 변동성)만 일관되게 효과가 있었고 나머지 신호는 약하거나 국내에서 반대였습니다.
- 신호 6개 추가(시장 폭, 공포지수, VIX 기간구조, 계절성, 200주선, 추세 돌파) 후에도 새로 일관된 효과를 보인 신호는 없었습니다. 국내에서는 시장 폭(-4.0%p)과 200주선(-1.6~-2.2%p)이 오히려 역효과였고, 미국 계절성은 앞뒤 절반의 방향이 엇갈렸습니다.
- 신호 경과일별 검증: 신규(0~10일) 구간이 지속 구간보다 좋다는 근거를 찾지 못했습니다(미국 중립 ETF 60일 평균 +2.9% vs 31일 이상 +4.4%, 국내 중립 ETF 상승 확률 53.7% vs 63.9%). 신규/지속 구분은 참고용입니다.
- 자동 보정은 미국만 채택(개선 +0.7%p, 우연 가능), 국내는 과적합으로 기본값 유지.
- 한계: 현재 상장 종목 위주(생존편향), 독립된 위기 구간이 적음, 종목 간 상관, 현금 이자·양도세 미반영.

## 알려진 한계
- 내 계좌의 권장 상한은 종목마다 따로 계산되어 합계가 가용 현금을 넘을 수 있음. 매매 기록(같은 차수 반복 추천 방지) 없음
- 도키 적정가는 영업현금흐름만 써서 설비투자가 큰 종목(LG화학, 기아, POSCO홀딩스 등)은 과대, 현대차는 금융 자회사 때문에 계산 불가, SK하이닉스는 이익 변동이 커 불안정
- 미국 종목은 적정가 없음(도키는 국내 개별주만). 자동 보정 대상은 웅덩이 7개 신호뿐
- PNG 아이콘 없음(SVG만), 오프라인 첫 방문 불가(서비스 워커는 방문 후 캐시)

## 아직 없음 (문서의 다음 단계)
거물 탭(SEC·DART), 영상 분석, GitHub Actions 배포와 개인정보 점검 스크립트, Cloudflare 실시간 프록시.

- 시세는 비공식 출처(야후)이며 지연·오차가 있을 수 있습니다.
