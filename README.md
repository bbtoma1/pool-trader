# 웅덩이 트레이더 (국내 전용)

국내 종목(코스피·코스닥 ETF와 대형주)의 하락 구간 분할매수 신호를 점수로 보여 주는 모바일 우선 PWA. 문서(`../01_PROMPTS.md`, `../02_BUILD_GUIDE.md`)를 기준으로 만든 구현입니다.
**투자 권유가 아닙니다.** 아래 "검증 결과 요약"을 먼저 읽으세요.

## 실행
```bash
python tools/update_data.py   # 시세 수집(야후 차트, 비공식). 접근 제한 시 우회하지 않고 기존 데이터 유지
python server.py              # http://localhost:8000
```
국내 개별주 적정가(도키): DART 인증키(영문·숫자 40자)를 환경변수 `DART_API_KEY`에 설정한 뒤
```bash
python tools/fund_kr.py       # 키 형식이 틀리면 값을 출력하지 않고 중단. --selftest 로 계산식만 점검
```
배포는 `DEPLOY.md` 를 보세요.

## 구현됨
- `data/universe.json`: 국내 23종목(지수 ETF 3, 섹터 ETF 7, 레버리지 1, 개별주 12)과 글로벌 변수 12개(미 금리·달러·원/달러·VIX·유가·금·구리·반도체지수, 코스피·코스닥)
- `tools/update_data.py`: 전체 이력 수집 → 이후 최근 1개월 병합, 실패 시 기존 값 유지. 수정주가 오류(0 이하)가 있으면 원 종가 사용. 유니버스에서 빠진 시세 파일은 삭제
- `tools/fund_kr.py`: DART 영업현금흐름·주식수(보통주+우선주)로 적정가, 공시일 이력(룩어헤드 방지), 금융업 제외
- `engine.js`: 웅덩이·도키·통합 점수, 1~3차, 과열 시 신규 매수 중단, 레버리지 제한
  - 웅덩이 신호 11개: 낙폭, 200일선 이격, 주봉·일봉 RSI, MACD, 변동성(코스피 20일 실현변동성 백분위), 지수 낙폭, 시장 폭(국내 섹터 ETF), 자체 공포지수, 200주선 근접, 추세 돌파
  - 화면은 신호가 켜진 지 11거래일 이내인 "신규"와 그 이후 "지속"을 구분. 내 계좌 권장 상한은 신규만 계산
- `regime.js`: 국내 시장 국면 판별. 유동성·경기·시장 내부 흐름·신용 스트레스·포지셔닝 5개 영역을 -2~+2로 채점하고 8개 국면으로 분류. 가격으로 계산 가능한 지표(코스피·섹터·글로벌 변수)만 쓰며, 없는 지표는 "확인 불가". 매수 점수에는 반영하지 않음
- `bt-worker.js`: 이벤트 연구(기준선·표본 외), 매매 시뮬레이션(수수료·거래세), 신호별 효과 점검, 자동 보정(워크포워드)
- 화면: 오늘 / 종목(차트·체크리스트·적정가) / 시장(국면·주요 시장 데이터) / 검증(중립 ETF 유니버스 분리) / 내 계좌(기기 내 저장). 서비스 워커·매니페스트
  - 내 계좌: 매매 기록(매수·매도·집행 차수)을 적으면 보유 수량에 자동 반영하고, 이미 집행한 차수는 다시 추천하지 않음. 권장 매수는 신규 신호를 점수 순으로 가용 현금 안에서 배분(합계가 가용 현금을 넘지 않음, 단일 종목 한도 적용)

## 검증 결과 요약 (2026-11-16 데이터 기준, 국내 종목만)
- 1차 신호 후 60일 상승 확률은 아무 날 매수 기준선(약 54.6%)과 같거나 낮았습니다(중립 ETF 49.8%, 전체 53.3%). 표본 외 구간도 50%대입니다.
- 매매 시뮬레이션은 100% 보유와 연수익률이 같고(5.3% vs 5.5%, 전체 9.3% vs 9.4%) 최대낙폭은 약 2~3%p 얕을 뿐입니다.
- 신호별로는 변동성만 일관되게 효과가 있었고, 시장 폭과 200주선은 국내에서 오히려 역효과였습니다.
- 신호 경과일별 검증: 신규(0~10일) 구간이 지속 구간보다 좋다는 근거를 찾지 못했습니다(상승 확률 신규 53.7%, 31일 이상 63.1%). 신규/지속 구분은 참고용입니다.
- 자동 보정은 채택 조건을 간신히 통과(검증 구간 초과수익 +0.6%p vs 기본 +0.5%p)했지만 차이가 노이즈 수준입니다.
- 한계: 현재 상장 종목 위주(생존편향), 독립된 위기 구간이 적음, 종목 간 상관, 현금 이자·양도세 미반영, 코스피가 6월 고점 대비 약 40% 하락한 구간이라 최근 표본이 한쪽으로 쏠림.

## 알려진 한계
- 내 계좌: 매매 기록은 이 기기의 브라우저에만 저장되어 다른 기기와 공유되지 않음. 현금은 기록으로 자동 갱신되지 않고 직접 입력. 수수료·세금·체결 슬리피지는 반영하지 않음
- 도키 적정가는 영업현금흐름만 써서 설비투자가 큰 종목(LG화학, 기아, POSCO홀딩스 등)은 과대, 현대차는 금융 자회사 때문에 계산 불가, SK하이닉스는 이익 변동이 커 불안정
- 자동 보정 대상은 웅덩이 신호뿐. 국면 탭은 국내 경기·수급 통계(PMI, 수출 속보치, 외국인 수급)를 쓰지 못해 신뢰도가 최대 "보통"
- PNG 아이콘 없음(SVG만), 오프라인 첫 방문 불가(서비스 워커는 방문 후 캐시)

## 아직 없음
거물 탭(DART 임원·5% 대량보유 공시), 영상 분석.

## 주의
- 개인 입력(현금·보유)과 비용·보정 설정은 브라우저에만 저장됩니다. 키·토큰은 코드나 저장소에 넣지 마세요(`DART_API_KEY`는 환경변수).
- 시세는 비공식 출처(야후)이며 지연·오차가 있을 수 있습니다.
